# Project: Fishing Zones Environment Redesign

## Architecture
The fishing zone environment system in `deck-and-tackle` renders side-view diorama encounters across 4 depth tiers:
- **Zone 1: Coastal Shoals / Innsmouth Coastal (0–30m)**
- **Zone 2: Kelp Shallows / Sunken Reef (30–60m)**
- **Zone 3: Abyssal Trench / Sunken Galleon (60–100m)**
- **Zone 4: Subterranean Sea Cave / Dagon Abyssal Lair (100m+)**

Data Flow and Rendering:
1. Encounter State: Selected fishing spot, species (`perch`, `pike`, `gar`, `dagon`), and depth determine the active `ZoneTier` (1..4) via `resolveZoneTier()`.
2. Environment Profile: Central `ZoneProfiles.ts` defines profiles for all 4 zones containing Skybox/Ceiling config, Wave dynamics config, Water column palette/lighting, and Environmental props.
3. Diorama Engine (`SideViewDiorama.ts`): Preloads all required sprite assets, eliminates static composite background overrides, and dynamically renders the active profile across sky/cavern ceiling (`0` to `waterLevelY`), water surface waves (`waterLevelY`), and underwater column (`waterLevelY` to `height`).
4. Standalone Preview (`side_view_battle_redesign_preview.html` generated by `build_full_preview.py`): Inlines all zone sprite assets and synchronizes stage toggles (Stage 1 to 4) with the corresponding zone environment profiles.

## Interface Contracts
### `ZoneProfiles.ts` &rarr; `SideViewDiorama.ts`
- `export type ZoneTier = 1 | 2 | 3 | 4;`
- `export interface ZoneProfile { tier: ZoneTier; id: string; name: string; sky: SkyboxConfig; waves: WaveConfig; waterColumn: WaterColumnConfig; ambientFishSprites: string[]; }`
- `export function resolveZoneTier(zoneType: WaterZoneType, speciesType?: SpeciesType, depthMeters?: number): ZoneTier;`
- `export function getZoneProfile(tier: ZoneTier): ZoneProfile;`
- `export const ZONE_PROFILES: Record<ZoneTier, ZoneProfile>;`

### `ZoneProfiles.ts` &rarr; Preview Generator (`build_full_preview.py`)
- The identical data structures and parameters (`sky`, `waves`, `waterColumn`, props) are represented in `STAGE_CONFIG[1..4]` in `build_full_preview.py`.
- Primary and secondary wave texture filenames, sky/cavern ceiling types, and prop filenames match exactly.
